# CS4250-Web-Srch-Recommender-Systms

## Assignment 4: Vector Space Model Search Engine

Ranks 100 documents against 5 queries using TF-IDF vectors (stopwords removed) and cosine similarity, then evaluates teh engine with the provided relevance judgments by computing Average Precision (AP) per query and the Mean Average Precision (MAP.

To run: run 'pip install -r requirements.txt', then run 'python3 vsm_search.py'
